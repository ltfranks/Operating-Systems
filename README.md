# **Operating Systems Projects**  

## **Overview**  
This repository contains various projects and assignments related to **Operating Systems (OS)** concepts. The projects explore key OS topics such as process management, memory allocation, scheduling algorithms, synchronization, and file systems.  

## **Contents**  
### 🖥 **Projects & Implementations**  
- **Process Scheduling** – Implementation of scheduling algorithms like **FCFS, SJF, Round Robin, and Priority Scheduling**.  
- **Memory Management** – Simulating paging and segmentation techniques for efficient memory allocation.  
- **Concurrency & Synchronization** – Implementing **mutexes, semaphores, and monitors** to manage thread synchronization.  
- **File System Simulation** – Working with **inode-based file systems** and performing operations like read, write, and seek.  
- **Inter-Process Communication (IPC)** – Using **pipes, shared memory, and message queues** for process interaction.  

## **Technologies Used**  
- **C / C++** – Low-level OS implementations  
- **POSIX Threads (pthreads)** – For multithreading  
- **Linux System Calls** – Process control, memory management, and IPC  
- **Shell Scripting** – Automating OS-related tasks
